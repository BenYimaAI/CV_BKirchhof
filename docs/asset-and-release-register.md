## Release classification
- **Draft:** not checked or approved
- **Review:** factual and disclosure checks in progress
- **Public-approved:** suitable for public website
- **Restricted-approved:** only for specifically authorized viewers through server-side checks
- **Withheld:** must never appear in the static/public site

The site itself is a non-published H01 development artifact. Private repository access does **not** imply that a Pages site is private.
